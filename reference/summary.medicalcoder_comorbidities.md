# Summaries of Comorbidities

Build summaries (counts and percentages) for each comorbidity and other
summary statistics by method.

## Usage

``` r
# S3 method for class 'medicalcoder_comorbidities'
summary(object, ...)
```

## Arguments

- object:

  a `medicalcoder_comorbidities` object generated by calling
  [`comorbidities()`](http://www.peteredewitt.com/medicalcoder/reference/comorbidities.md)

- ...:

  additional parameters, not currently used

## Value

Either a list or a `data.frame`.

## Details

If a `medicalcoder_comorbidities` object has been modified so that it no
longer has the structure required by medicalcoder's summary methods,
summary falls back to the next applicable summary method with a warning.
